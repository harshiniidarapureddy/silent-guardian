# Silent Guardian: AI-Powered Healthcare Triage & Community Safety Net

## Overview
Silent Guardian is an AI-powered healthcare triage ecosystem designed to eliminate medical hesitation, prevent unverified health anxiety, and accelerate emergency response. 

## Features
- **AI Triage Assistant:** Powered by Gemini 3 Flash for cautious, non-diagnostic symptom guidance and specialist routing.
- **Role-Based Portals:** Segmented dashboards for Patients, Hospital Managers, and Super Admins.
- **Hospital Finder & Bed Tracking:** Geolocation-based mapping with real-time bed capacity and ratings.
- **Community Safety Net:** Blood donation matching, emergency SOS alerts, and First-Aid responder dispatch.
- **Multi-Language Awareness Feed:** Preventive health education in English, Hindi, Telugu, Tamil, and Spanish.

## Tech Stack
- **Frontend:** React, Tailwind CSS, shadcn/ui
- **Backend:** FastAPI, Python, MongoDB
- **AI Integration:** Gemini 3 Flash API
